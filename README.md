# DogConnect

Opening DogConnect launches SSRDOG Lite. When SSRDOG explicitly reports disconnected, the enabled accessibility service makes one state-aware attempt to activate its central connection control. If SSRDOG already reports connected, DogConnect never clicks the switch. Ambiguous controls are not clicked. First-time Android VPN consent remains a system confirmation. In-app updates and automatic signed GitHub Releases remain enabled.

Enable DogConnect's accessibility service in HarmonyOS settings for connection automation. Keep the signing keystore backed up offline.
